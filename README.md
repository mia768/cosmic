# cosmic — BEYOND

Интерактивный русскоязычный космический атлас: 3D-планеты на Three.js, выбор восьми планет, карта Солнечной системы, образовательные карточки и факты.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Для установки в cloud-среде с недоступным домашним каталогом: `npm ci --cache /workspace/.npm`.

Текстуры Земли и облаков: https://github.com/turban/webgl-earth/tree/master/images. Шрифты Manrope и Space Grotesk загружаются через Google Fonts; при отсутствии сети используются системные шрифты. Остальные иллюстрации созданы средствами CSS. Масштабы на карте условные. Без WebGL отображается текстурированная Земля.
